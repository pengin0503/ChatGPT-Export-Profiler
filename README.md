# ChatGPT Export Profiler

**日本語** | [English](README.en.md)

ChatGPTのエクスポートZIPをブラウザ内で分析するアプリです。会話、モデル、時間帯、ツール、データ品質、仮定に基づく費用を確認し、集計結果をJSON・CSV・Markdownで出力できます。

## プライバシーと精度

選択したZIPはブラウザ内で処理され、アプリから分析サービスへアップロードされません。元のZIPとメッセージ本文はIndexedDBに保存しません。一方、会話タイトル、日時、モデル、集計値、設定などの派生データは端末内に保存される場合があります。保存・削除の詳細は[プライバシー](docs/privacy.md)をご覧ください。

表示値は、エクスポートから確認できる値、そこから算出した値、仮定に基づく推定値を区別します。トークン数やAPI換算費用はOpenAIの請求額や内部計測の代わりではありません。[データ精度](docs/data-accuracy.md)も参照してください。

## 使用方法

Node.js 22以上とnpmを用意し、リポジトリのフォルダで実行します。

```bash
npm ci
npm run dev
```

表示されたローカルアドレスをブラウザで開き、ChatGPTのエクスポートZIPを選択します。本番ビルドは `npm run build`、プレビューは `npm run preview` です。

## オフライン利用

対応ブラウザでは、対応する安全なオリジンから本番版を開いてPWAをインストール・キャッシュすると、以降オフラインで再起動できます。`npm run make:offline` で作成するZIPには、アプリと `127.0.0.1` のみで待ち受ける小さなNodeサーバーが含まれます。物理iPadのSafari・Orionでの動作は自動テストだけでは保証されません。
